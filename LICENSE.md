# VoxNexus license FAQ

This is a plain-language companion to [`LICENSE`](LICENSE). The legal text in `LICENSE` controls if anything here disagrees. This is not legal advice.

**VoxNexus is source-available software.** The source code is publicly available for inspection, contribution, and private personal use. The license does not permit commercial use, public hosting, redistribution, or reuse of VoxNexus code in other projects without separate written permission.

It is **not open source** as defined by the Open Source Initiative. There is no OSI-approved license on this repository (not MIT, Apache, GPL, AGPL, or similar). Public source code ≠ open source ≠ public-use software.

## What you may do

- Read and study the source.
- Build and run **one private instance** for personal, non-commercial use.
- Invite household members or friends to that private instance.
- Make private changes **only** so you can run that instance.
- Fork the repository on the hosting service (for example GitHub) solely to view, study, or contribute under the [CLA](CLA.md).

## What you may not do (without a separate written license)

- Use VoxNexus commercially, including inside a company.
- Run a **public instance** (open registration, advertised community, or anything beyond a private personal group).
- Copy this code into other software, including hobby projects.
- Redistribute the software or your modifications, except by contributing to the copyright holder’s official repository under the [CLA](CLA.md).
- Offer VoxNexus as hosted/SaaS, or sell a product whose value comes substantially from this software.
- Relicense the code.

A platform fork used only for viewing, studying, or contributing does **not** grant any of the permissions above.

## Contributions

Patches are accepted only under [`CLA.md`](CLA.md). Contributors retain copyright in their contributions and grant the copyright holder a perpetual, irrevocable license that includes sublicensing and dual-licensing rights. That lets the project keep distributing under this source-available license and, later, offer a separate commercial license without needing new permission from each contributor.

## Commercial, public, or OEM use

Those uses are possible **only** by written agreement with the copyright holder (for example company use, public communities, hosted instances, or OEM).

## GitHub / hosting-service forks

Making this repository public on a host such as GitHub means users can view and fork it through that host’s own features. That limited platform permission does not override this license: it does not allow public deployment, commercial use, redistribution of builds, or incorporating VoxNexus into another product.

## “Not OSI” in one sentence

You can look at the code and run a private personal instance. You cannot treat this repository as free-to-reuse open source.
