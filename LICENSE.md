# VoxNexus license FAQ

This is a plain-language companion to [`LICENSE`](LICENSE). The legal text in `LICENSE` controls if anything here disagrees. This is not legal advice.

**VoxNexus is source-available. It is not open source** as defined by the Open Source Initiative. There is no OSI-approved license on this repository (not MIT, Apache, GPL, AGPL, or similar).

## What you may do

- Read and study the source.
- Build and run **one private instance** for personal, non-commercial use.
- Invite household members or friends to that private instance.
- Make private changes **only** so you can run that instance.

## What you may not do (without a separate written license)

- Use VoxNexus commercially, including inside a company.
- Run a **public instance** (open registration, advertised community, or anything beyond a private personal group).
- Copy this code into other software, including hobby projects.
- Redistribute the software or your modifications, except by contributing to the copyright holder’s official repository under the [CLA](CLA.md).
- Offer VoxNexus as hosted/SaaS, or sell a product whose value comes substantially from this software.
- Relicense the code.

## Contributions

Patches are accepted only under [`CLA.md`](CLA.md). That agreement lets the copyright holder use your contribution and dual-license it.

## Commercial, public, or OEM use

Those uses are possible **only** by written agreement with the copyright holder.

## “Not OSI” in one sentence

You can look at the code and run a private personal instance. You cannot treat this repository as free-to-reuse open source.
